# 全部生命・我在語錄 Web App (`totality_of_life_app.html`)

靈感源自**楊定一博士《全部生命系列》**（[全部生命系列官網](https://totality-of-life.com/)），以「現代極簡・自然意象・東方留白美學」打造的跨裝置（手機、平板、電腦桌面）**我在語錄**與生活練習網路應用程式。品牌副標題精簡為「每日靜心與生活練習」，並搭配專屬「愛心小鳥」品牌 Logo，整體體驗如同一本每天願意翻閱的紙本生活手札，陪伴讀者在日常行住坐臥中隨時回到「這裡、現在」。

### 2. 視覺元素與排版原則

* **專屬品牌 Logo**：導覽列左上角與網頁圖示（Favicon）採用您提供的專屬「暖金愛心小鳥」Logo，以 Base64 內嵌於單一檔案中。

* **細緻紙張質感**：背景採用極低透明度的微粒紙張紋理（Radial Paper Grain），溫潤不刺眼且完全不影響文字清晰度。

* **自然意象細線插畫**：摒棄繁複宗教圖騰、大量蓮花與強烈漸層，改以極簡細線勾勒**遠山、晨光、葉片與水波**。

* **充足留白與單一視覺焦點**：主畫面模擬翻開的生活手札，左側設有暖金書頁側線，單一主要行動按鈕（「寫入心情手札」）搭配低調細線工具列；並已移除頂部重複的「頁首每日一句」橫幅列，讓手機與桌面閱讀視野更清爽開闊。

### 3. 字體與三段閱讀尺寸（Typography & Reading Scale）

* **標題與語錄**：採用清晰的繁體中文襯線體（`Noto Serif TC`），呈現書卷氣息。

* **內文、按鈕與導覽**：採用高易讀性的繁體中文無襯線體（`Noto Sans TC` / `Inter`），避免使用不易閱讀的書法字。

* **三段式字體大小切換**：頂部導覽列內建 **「標準 / 大字 / 特大字」** 切換器，一鍵同步縮放語錄、詳情解析、生活練習步驟與心情手札內文，並自動記憶於瀏覽器。

## 二、六大核心功能與導覽架構

導覽列依使用動線排列，並將「小工具」**配置於**「資料來源與上傳」的左邊：

1. **每日一句與練習**：

   * 顯示當日《全部生命系列》**我在語錄**、出處書籍與原始參考連結。

   * **語句詳情與生活練習**：包含「語句深層意涵」與「今日生活練習三步驟指引」，支援語音朗讀與練習打卡。

   * **互動式呼吸與靜坐練習計時器（支援手動調整時間長短 & 吸吐不同音效）**：

     * **瞬間臣服**：可透過滑桿、加減鈕或數字框手動調整時間，**最短 1 分鐘、最長 15 分鐘**。

     * **諧振呼吸（5秒吸 / 5秒吐）**：可手動調整時間，**最短 5 分鐘、最長 30 分鐘**；**吸氣與吐氣採用不同引導音效**——吸氣時響起清亮上揚和弦音（`432Hz → 540Hz`），吐氣時響起溫潤沉降木質低音缽（`384Hz → 256Hz`），並提供「🔊 試聽吸氣音」與「🔉 試聽吐氣音」按鈕。

     * **靜坐三原則**：可手動調整時間，**最短 15 分鐘、最長 60 分鐘**。

2. **主題分類與搜尋**：

   * 支援八大核心分類篩選（依序排列）：**臣服與參、感恩、靜坐與呼吸、在、覺、樂、創傷與療癒、這裡、現在、祈禱與祝福、靈光乍現**。

   * **分類歸併與「💫 靈光乍現」個人靈感專區**：

     * 原「我是誰」類別的所有語錄已全數歸入「🌿 臣服與參」。

     * **「💫 靈光乍現」**位於「祈禱與祝福」右邊，為**記錄自己靈感的專屬區域（只由自己上傳，不載入網路語錄）**；點選該分類時會直接顯示「個人靈感快速記錄」輸入框，亦可從「資料來源與上傳」新增個人靈感。

   * 支援關鍵字即時搜尋與來源屬性篩選（所有來源／個人上傳／全部生命系列書籍與網路）。

3. **心情手札**：

   * 結合當日共修語句、心境能量標籤（平靜安住、充滿感恩、臣服接納、覺察念頭、身體放鬆、轉化煩惱）與身體呼吸觀察。

   * 支援新增、編輯、刪除與一鍵匯出 `.txt` 備份檔。

4. **我的收藏**：

   * 集中管理所有標記愛心的我在語錄。

   * 內建「我在語錄分享字卡工坊」：提供山林靜謐（鼠尾草綠）、晨曦暖金（淡杏暖米）、宣紙水墨三種極簡底色，可一鍵下載高畫質 `.png` 圖卡。

5. **小工具（位於「資料來源與上傳」左邊）**：

   * **手機桌面小工具（iOS / Android）**：提供小（2x2）、中（4x2）尺寸預覽、「加入主畫面（Add to Home Screen）」教學，以及 Scriptable / KWGT 專用 `.json` 資料檔下載。

   * **電腦桌面小工具（Mac / Windows）**：支援在畫面右下角開啟常駐懸浮小視窗，或下載獨立 `.html` 桌面小工具檔案。

   * **網頁頁首小工具（Header Banner）**：提供外部網站橫幅預覽與一鍵複製 HTML 嵌入碼功能。

6. **資料來源與上傳（管理者專屬功能：依 31 本書搜尋、先找語錄再歸類、YouTube / MP3 解讀 & 嚴格防重複機制）**：

   * **📚 A. 依照楊定一博士 31 本書標題搜尋語錄**：

     * 內建完整 **31 本《全部生命系列》書目清單**，可選擇「🌟 全部 31 本著作（輪流搜尋語錄）」或指定單本著作進行深度檢索：
       1. 《真原醫》｜2. 《靜坐》｜3. 《全部的你》｜4. 《螺旋舞》｜5. 《神聖的你》｜6. 《不合理的快樂》｜7. 《我是誰》｜8. 《集體的失憶》｜9. 《落在地球》｜10. 《定》｜11. 《奇蹟》｜12. 《結構調整１（透過運動和療效姿勢結構調整）》｜13. 《十字路口》｜14. 《插對頭》｜15. 《時間的陷阱》｜16. 《短路》｜17. 《好睡》｜18. 《頭腦的東西》｜19. 《無事生非》｜20. 《清醒地睡》｜21. 《我：弄錯身分的個案》｜22. 《豐盛》｜23. 《結構調整２（最簡單，居家隨時做的結構調整運動）》｜24. 《唯識》｜25. 《必要的創傷》｜26. 《轉捩點》｜27. 《療癒的飲食與斷食》｜28. 《呼吸，為了療癒》｜29. 《水仙》｜30. 《中道（走向心的道路）》｜31. 《徹底的信仰，根本的療癒》。

   * **🔄 B. 「先找出語錄，再歸類」雙階段流程（不依類別名稱找語錄）**：

     * **步驟 1（先找出語錄）**：系統**絕不以類別名稱作為搜尋關鍵字**，而是直接依照上述「楊定一 31 本書標題」、「YouTube 共修影片字幕」與「Podcast MP3 音頻內容」從網路與內建驗證庫（已擴充至 **96+ 則不重複精選語錄**）中先找出原始語錄。

     * **步驟 2（再依語意自動歸類）**：找出語錄後，系統才會透過語意分析引擎（`classifyQuoteTopic`）分析該句話的核心意涵，自動將其歸類至對應的七大公開主題（臣服與參、感恩、靜坐與呼吸、在、覺、樂、創傷與療癒、這裡、現在、祈禱與祝福），並自動生成深層意涵與三步驟練習。

   * **🎬 解讀 YouTube 影片內容／CC 字幕 & 🎵 解讀 MP3 音檔內容 自動產生語錄**：

     * **YouTube 內容解讀**：內建 11 支官方 YouTube 共修影片完整逐字稿庫，並支援貼上任意 YouTube 影片網址或 CC 字幕段落，自動斷句萃取出不重複語錄後再自動歸類。

     * **MP3 音檔與 Podcast 解讀**：支援選取本機 `.mp3` / `.m4a` / `.wav` 音檔（透過 Web Audio API 與 Web Speech 即時語音辨識轉譯）或一鍵連線解讀線上 Podcast MP3 音頻庫，直接產生純文字「我在語錄」。

   * **🔒 C. GitHub 儲存空間說明與「管理者專屬功能（Admin Mode）」**：

     * **不會增加 GitHub 儲存空間**：網站部署至 GitHub Pages 後為純前端靜態網頁（Static Web App）。任何人在網頁上點擊「一鍵載入新增語錄」或於「資料來源與上傳」新增語錄，資料皆僅儲存在**使用者自己的瀏覽器本機記憶體（`localStorage`）**，**完全不會寫回 GitHub 儲存庫（0 Byte 伺服器寫入），因此絕對不會增加 GitHub 的儲存空間**。

     * **管理者專屬模式（預設密碼 `8888`，可自訂修改）**：為了避免一般訪客誤觸管理功能，已將全站的「⚡ 一鍵載入新增語錄」按鈕與「資料來源與上傳」區塊設為**管理者專屬功能**。點擊頂部導覽列的「🔓 管理者模式 / 🔒 訪客模式」按鈕即可一鍵鎖定為訪客瀏覽模式（自動隱藏所有管理與載入按鈕），需輸入管理者通行碼方可解鎖。

   * **語錄去重與防重複規則（新增語錄不能與現有語錄重複）**：

     * 無論透過「個人單筆新增」、「批次文字貼上」、「檔案上傳（`.txt` / `.csv` / `.json`）」、「⚡ 一鍵載入新增語錄（31 本書搜尋）」或「🎬 YouTube ／ 🎵 MP3 內容解讀」，系統都會即時比對現有語錄庫；若發現語錄內容已存在，會自動攔截或略過，確保新增語錄絕對不會與現有語錄重複。

## 三、跨裝置操作與部署說明

* **單一檔案免安裝架構**：整個應用程式封裝於單一 `totality_of_life_app.html` 檔案中，無須後端伺服器即可在手機、平板與電腦瀏覽器直接開啟運行。

* **本機資料持久化**：所有個人上傳的語錄與靈感、收藏清單、心情手札與字體大小偏好，皆自動去重並儲存於瀏覽器 `localStorage` 中，離線亦可使用。

* **部署至公開網頁**：可將 `totality_of_life_app.html` 重新命名為 `index.html`，直接上傳至 GitHub Pages、Cloudflare Pages 或 Vercel，即可透過網址在手機與電腦間隨時開啟使用。
