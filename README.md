# 全部生命・我在語錄 Web App (`totality_of_life_app.html`)

靈感源自**楊定一博士《全部生命系列》**（[全部生命系列官網](https://totality-of-life.com/)），以「現代極簡・自然意象・東方留白美學」打造的跨裝置（手機、平板、電腦桌面）**我在語錄**與生活練習網路應用程式。品牌副標題精簡為「每日靜心與生活練習」，並搭配專屬「愛心小鳥」品牌 Logo，整體體驗如同一本每天願意翻閱的紙本生活手札，陪伴讀者在日常行住坐臥中隨時回到「這裡、現在」。

## 二、六大核心功能與導覽架構

導覽列依使用動線排列，並將「小工具」**配置於**「資料來源與上傳」的左邊：

1. **每日一句與練習**：

   * 顯示當日《全部生命系列》**我在語錄**、出處書籍與原始參考連結。

   * **語句詳情與生活練習**：包含「語句深層意涵」與「今日生活練習三步驟指引」，支援語音朗讀與練習打卡。

   * **互動式呼吸與靜坐練習計時器（支援手動調整時間長短 & 吸吐不同音效）**：

     * **瞬間臣服**：可透過滑桿、加減鈕或數字框手動調整時間，**最短 1 分鐘、最長 15 分鐘**。

     * **諧振呼吸（5秒吸 / 5秒吐）**：可手動調整時間，**最短 5 分鐘、最長 30 分鐘**；**吸氣與吐氣採用不同引導音效**——吸氣時響起清亮上揚和弦音（`432Hz → 540Hz`），吐氣時響起溫潤沉降木質低音缽（`384Hz → 256Hz`），並提供「🔊 試聽吸氣音」與「🔉 試聽吐氣音」按鈕。

     * **靜坐三原則**：可手動調整時間，**最短 15 分鐘、最長 60 分鐘**。

2. **主題分類與搜尋**：

   * 支援八大核心分類篩選（依序排列）：**臣服與參、感恩、靜坐與呼吸、在、覺、樂、創傷與療癒、這裡、現在、祈禱與祝福、靈光乍現**。

   * **分類歸併與「💫 靈光乍現」個人靈感專區**：

     * 原「我是誰」類別的所有語錄已全數歸入「🌿 臣服與參」。

     * **「💫 靈光乍現」**位於「祈禱與祝福」右邊，為**記錄自己靈感的專屬區域**；點選該分類時會直接顯示「個人靈感快速記錄」輸入框。

   * 支援關鍵字即時搜尋與來源管道篩選（所有來源／31本書籍與網路自動檢索／YouTube 影片解讀／MP3 與 Podcast 音頻解讀／靈光乍現）。

3. **心情手札**：

   * 結合當日共修語句、心境能量標籤（平靜安住、充滿感恩、臣服接納、覺察念頭、身體放鬆、轉化煩惱）與身體呼吸觀察。

   * 支援新增、編輯、刪除與一鍵匯出 `.txt` 備份檔。

4. **我的收藏**：

   * 集中管理所有標記愛心的我在語錄。

   * 內建「我在語錄分享字卡工坊」：提供山林靜謐（鼠尾草綠）、晨曦暖金（淡杏暖米）、宣紙水墨三種極簡底色，可一鍵下載高畫質 `.png` 圖卡。

5. **小工具（位於「資料來源與上傳」左邊・全面改良零門檻設計）**：

   * **📱 1. 手機桌面與鎖屏 Widget（免寫程式・零門檻三合一）**：

     * **方法 A：開啟「手機極簡滿版 Widget 模式」**：一鍵進入無選單干擾的大字版全螢幕模式（內含今日語錄、換句按鈕與 1 分鐘瞬間臣服呼吸圓環），在此畫面點選手機瀏覽器「分享 ➔ 加入主畫面」，即可從手機桌面一秒直達極簡大字卡。

     * **方法 B：一鍵下載「今日手機鎖屏／桌面壁紙（9:16 高畫質 `1080x1920` PNG）」**：自動預留頂部 35% 空間避開 iPhone / Android 鎖屏時鐘，儲存至相簿設為鎖定畫面後，每次拿起手機免解鎖就能看見今日我在語錄。

     * **方法 C：一鍵複製 30 則語錄包**：可直接貼入 iPhone / Android 內建「備忘錄（Notes）」桌面小工具。

   * **💻 2. 電腦桌面常駐小工具（Windows / Mac 跨視窗常駐與獨立執行版）**：

     * **🪟 啟動「離開網頁也常駐置頂」獨立桌面小視窗**：透過瀏覽器原生 `Document Picture-in-Picture API`（子母畫面永遠置頂技術）與獨立彈出視窗（Popup Mini-Window），即使切換去其他網站、打開 Word / Excel 或將主網頁切到背景，桌面小視窗依然常駐於畫面最上層並可獨立運作。

     * **🪟 下載 Windows 專用獨立桌面小工具（`.hta` 免瀏覽器邊框應用程式）**：專為 Windows 系統設計，下載後雙擊即可直接以獨立桌面小視窗執行。

     * **⬇ 下載跨平台電腦桌面小工具（`.html` 完整離線互動版）**：將目前題庫中**全部 96+ 則語錄完整封裝於單一檔案內**，在 Windows 或 Mac 雙擊打開即可離線使用「↻ 換下一句語錄」、「🧘 1分鐘瞬間臣服呼吸計時器（含吸吐音效）」、「🎨 4 種底色切換」與「Aa 字體縮放」。

   * **🌐 3. 網頁頁首小工具（Header Banner）**：提供外部網站橫幅預覽與一鍵複製 HTML 嵌入碼功能。

## 三、跨裝置操作與部署說明

* **單一檔案免安裝架構**：整個應用程式封裝於單一 `totality_of_life_app.html` 檔案中，無須後端伺服器即可在手機、平板與電腦瀏覽器直接開啟運行。

* **本機資料持久化（不佔用 GitHub 空間）**：所有自動載入的語錄、收藏清單、心情手札與字體大小偏好，皆自動去重並儲存於瀏覽器 `localStorage` 中，離線亦可使用，且完全不佔用 GitHub 儲存空間。

* **部署至公開網頁**：可將 `totality_of_life_app.html` 重新命名為 `index.html`，直接上傳至 GitHub Pages、Cloudflare Pages 或 Vercel，即可透過網址在手機與電腦間隨時開啟使用。
