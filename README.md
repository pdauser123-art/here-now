# 全部生命・我在語錄 Web App (`totality_of_life_app.html`)

靈感源自**楊定一博士《全部生命系列》**（[全部生命系列官網](https://totality-of-life.com/)），以「現代極簡・自然意象・東方留白美學」打造的跨裝置（手機、平板、電腦桌面）**我在語錄**與生活練習網路應用程式。品牌副標題精簡為「每日靜心與生活練習」，並搭配專屬「愛心小鳥」品牌 Logo，整體體驗如同一本每天願意翻閱的紙本生活手札，陪伴讀者在日常行住坐臥中隨時回到「這裡、現在」。

### 2. 視覺元素與雙列表頭排版（電腦版與手機版皆獨立兩列、不擁擠）

* **專屬品牌 Logo**：導覽列左上角與網頁圖示（Favicon）採用您提供的專屬「暖金愛心小鳥」Logo，以 Base64 內嵌於單一檔案中。

* **雙列式表頭設計（電腦版與手機版皆將導覽列獨立於第二列）**：

  * **表頭第一列（品牌與快速控制列）**：左側為品牌 Logo 與標題；右側配置 **「標準 / 大字 / 特大字」** 閱讀尺寸切換膠囊，並在電腦版表頭第一列「標準 大字 特大字」右邊配置 **「🖥️ 桌面小視窗」** 功能鈕（一鍵啟動離開網頁也常駐置頂的獨立桌面小視窗）。

  * **表頭第二列（獨立六大主題導覽列）**：無論在電腦版或手機版，「每日一句與練習、主題分類與搜尋、心情手札、我的收藏、小工具、資料來源與上傳」六大導覽分頁皆單獨顯示於表頭第二列，完全不與第一列 Logo 擠在一起，版面寬敞舒展。

* **細緻紙張質感與自然意象細線插畫**：背景採用極低透明度的微粒紙張紋理（Radial Paper Grain），並以極簡細線勾勒**遠山、晨光、葉片與水波**。

## 二、六大核心功能與導覽架構

導覽列依使用動線排列，並將「小工具」**配置於**「資料來源與上傳」的左邊：

1. **每日一句與練習（自然小鳥鳴叫呼吸音效）**：

   * 顯示當日《全部生命系列》**我在語錄**、出處書籍與原始參考連結。

   * **語句詳情與生活練習**：包含「語句深層意涵」與「今日生活練習三步驟指引」，支援語音朗讀與練習打卡。

   * **互動式呼吸與靜坐練習計時器（支援手動調整時間長短 & 吸氣／吐氣不同小鳥鳴叫聲）**：

     * **瞬間臣服**：可透過滑桿、加減鈕或數字框手動調整時間，**最短 1 分鐘、最長 15 分鐘**。

     * **諧振呼吸（5秒吸 / 5秒吐）**：可手動調整時間，**最短 5 分鐘、最長 30 分鐘**；**吸氣與吐氣採用兩種不同的自然小鳥鳴叫聲**——

       * **🐦 吸氣音（清晨畫眉／雲雀雙連音上揚鳥鳴）**：清脆輕快的雙連音上揚鳥鳴（`1850Hz → 2750Hz` 與 `2050Hz → 3150Hz` 帶自然鳥鳴微顫音），引導身心輕盈吸氣。

       * **🕊️ 吐氣音（山林青鳥／夜鶯溫潤婉轉沉降鳥鳴）**：溫柔圓潤的低迴下滑鳥鳴（`1480Hz → 980Hz` 與 `1180Hz → 760Hz`），引導雙肩自然下沉、緩慢吐氣。

       * 提供「🐦 試聽吸氣鳥鳴」與「🕊️ 試聽吐氣鳥鳴」按鈕。

     * **靜坐三原則**：可手動調整時間，**最短 15 分鐘、最長 60 分鐘**。

2. **主題分類與搜尋**：

   * 支援八大核心分類篩選（依序排列）：**臣服與參、感恩、靜坐與呼吸、在、覺、樂、創傷與療癒、這裡、現在、祈禱與祝福、靈光乍現**。

   * **分類歸併與「💫 靈光乍現」個人靈感專區**：

     * 原「我是誰」類別的所有語錄已全數歸入「🌿 臣服與參」。

     * **「💫 靈光乍現」位於「祈禱與祝福」右邊，為記錄自己靈感的專屬區域**；點選該分類時會直接顯示「個人靈感快速記錄」輸入框。

   * 支援關鍵字即時搜尋與來源管道篩選（所有來源／31本書籍與網路自動檢索／YouTube 影片解讀／MP3 與 Podcast 音頻解讀／靈光乍現）。

3. **心情手札（自動導入當日「每日一句」語錄）**：

   * **搭配共修語句自動導入「每日一句」**：撰寫心情手札時，無須再從冗長的下拉選單手動挑選，系統會**直接自動導入並同步顯示當前的「每日一句」語錄與書名出處**。

   * 結合心境能量標籤（平靜安住、充滿感恩、臣服接納、覺察念頭、身體放鬆、轉化煩惱）與身體呼吸觀察，支援新增、編輯、刪除與一鍵匯出 `.txt` 備份檔。

4. **我的收藏**：

   * 集中管理所有標記愛心的我在語錄。

   * 內建「我在語錄分享字卡工坊」：提供山林靜謐（鼠尾草綠）、晨曦暖金（淡杏暖米）、宣紙水墨三種極簡底色，可一鍵下載高畫質 `.png` 圖卡。

5. **小工具（位於「資料來源與上傳」左邊・解決 Android 捷徑與 Windows 安全性限制）**：

   * **📱 1. 手機桌面與鎖屏 Widget（Android / iPhone 建立捷徑永久鎖定極簡模式）**：

     * **方法 A：鎖定「Android / iPhone 極簡桌面模式」**：點擊後系統會同時將極簡模式狀態寫入本機 `localStorage`（`tol_mobile_widget_mode_v1 = true`）並鎖定網址為 `#widget`。在 Android 或 iPhone 點選瀏覽器「**新增至主畫面／建立捷徑**」後，**每次從手機桌面捷徑點開都會 0 秒直接進入「極簡大字每日一句＋小鳥呼吸」畫面，絕對不會跳回完整模式**！（唯有主動點擊右上角「← 返回完整手札」才會解除鎖定）。

     * **方法 B：一鍵下載「今日手機鎖屏／桌面壁紙（9:16 高畫質 `1080x1920` PNG）」**：自動預留頂部 35% 空間避開手機鎖屏時鐘，設為鎖定畫面後拿起手機免解鎖即可閱讀。

     * **方法 C：一鍵複製 30 則語錄包**：可直接貼入 iPhone / Android 內建「備忘錄（Notes）」桌面小工具。

   * **💻 2. 電腦桌面常駐小工具（Windows 免安全性攔截版 ＆ 離開網頁常駐置頂小視窗）**：

     * **🪟 啟動「離開網頁也常駐置頂」獨立桌面小視窗**：可在電腦版表頭第一列右上角點擊「**🖥️ 桌面小視窗**」或於小工具分頁啟動，透過 `Document Picture-in-Picture API` 或獨立彈出視窗，即使切換去其他網站或使用其他軟體，小視窗依然獨立常駐並內建小鳥呼吸計時器。

     * **🪟 下載 Windows 免安全性攔截・獨立桌面小工具（`.html` 雙擊即開版）**：

       * **Windows 安全性規則說明**：Windows 10/11 的附件管理員（Attachment Manager）會對網路下載的 `.hta` 檔案標記 `Zone.Identifier (MOTW)` 並彈出「網際網路安全性設定導致無法開啟一或多個檔案」。

       * **改善方式**：改為下載 **100% 不受 Windows 安全性阻擋的獨立 `.html` 桌面應用程式**（內建「🪟 獨立小視窗」一鍵無邊框彈出鈕、完整 96+ 則語錄庫、小鳥呼吸計時器、4 種底色與字體縮放），在 Windows 下載後雙擊即可 100% 直接開啟！（若欲開啟舊 `.hta` 檔，亦可對檔案按滑鼠右鍵 ➔ 內容 ➔ 勾選右下角「解除封鎖」➔ 確定）。

   * **🌐 3. 網頁頁首小工具（Header Banner）**：提供外部網站橫幅預覽與一鍵複製 HTML 嵌入碼功能。

## 三、跨裝置操作與部署說明

* **單一檔案免安裝架構**：整個應用程式封裝於單一 `totality_of_life_app.html` 檔案中，無須後端伺服器即可在手機、平板與電腦瀏覽器直接開啟運行。

* **本機資料持久化（不佔用 GitHub 空間）**：所有自動載入的語錄、收藏清單、心情手札與字體大小偏好，皆自動去重並儲存於瀏覽器 `localStorage` 中，離線亦可使用，且完全不佔用 GitHub 儲存空間。

* **部署至公開網頁**：可將 `totality_of_life_app.html` 重新命名為 `index.html`，直接上傳至 GitHub Pages、Cloudflare Pages 或 Vercel，即可透過網址在手機與電腦間隨時開啟使用。
